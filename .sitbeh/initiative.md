# Initiative

**Product:** Human tasks, a bb plugin. Agents hand the user steps only a human
can do; the user does them; the requesting agent resumes; over time the user
hands recurring chores to agents.

**Business goal:** no agent stays blocked on a human longer than it must, and
the number of chores the user still does by hand goes down over time.
Signals: median time from task created to done; share of done tasks whose
agent resumed; number of chores handed off to agents.
