# Situations

1. **Unblock now.** A builder running several agents across projects, in the
   middle of other work, when an agent hits a step it cannot take (a key, a DNS
   record, a console click), wanting to unblock it in minutes without losing
   their own context. → scenario-unblock-now.md
2. **Clear the queue.** A builder coming back to the list later (evening, next
   morning, on a phone), wanting to clear a batch of manual steps and be sure
   every agent actually picked its work back up. → scenario-clear-the-queue.md
3. **Stop doing it.** A builder who notices they keep doing the same chore for
   agents, wanting an agent to do it this time or from now on, through an MCP
   server, API access, a CLI login, their browser, a new tool, or a skill.
   → scenario-stop-doing-it.md
